# MindMate

MindMate is an AI-powered study coach that proactively guides students on what to study next.

## Vision

Help every student make better academic decisions through personalized AI guidance.

## MVP Features

- AI Coach
- Dashboard
- Smart Notes
- Study Planner
- Habit Tracker
- Mood Tracker

## Tech Stack

- GitHub
- Firebase
- Supabase
- Google AI Studio (Gemini)
- Figma

## Development Philosophy

Build fast.
Validate with users.
Improve through iteration.

Functionality before beauty.
